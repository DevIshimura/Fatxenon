# 🎮 FatXenon

**A modern FATX storage manager for Xbox 360.**

FatXenon is a Windows application designed to manage **Xbox 360 FATX storage devices** directly from your PC.

It provides a simple and modern interface for browsing and managing files stored on Xbox 360 HDDs and compatible FATX devices.

> **Developed by Ishimura**

---

## ✨ Features

* 💾 Detect Xbox 360 FATX storage devices
* 📂 Browse FATX partitions and directories
* 📤 Copy files from Windows to FATX
* 📥 Extract files from FATX to Windows
* 📁 Copy complete folders
* ✏️ Create folders
* 🔄 Move and rename files
* 🗑️ Delete files and folders
* 📊 File transfer progress
* 🔍 Browse Xbox 360 storage structures
* ⚡ Direct FATX device access
* 🎮 Designed specifically for Xbox 360 storage management

---

## 💽 Supported Storage

FatXenon is designed to work with FATX-formatted storage used by the Xbox 360, including:

* Xbox 360 internal HDDs
* Xbox 360 external FATX storage
* Compatible USB storage
* FATX partitions


---

## 🚀 Main Goal

The goal of FatXenon is to make Xbox 360 FATX storage management easier without requiring users to manually deal with the FATX filesystem structure.

The project focuses on:

**Speed • Simplicity • Stability • Xbox 360 Compatibility**

---

## ⚠️ Important

Always keep backups of important Xbox 360 data before modifying a FATX storage device.

Unexpected disconnections, corrupted filesystem structures, hardware failures, or interrupted write operations may result in data loss.

FatXenon is provided without warranty. Use it at your own risk.

---

## 🛠️ Development

FatXenon is developed for **Windows** using **VB.NET / .NET Framework**.

The project interacts directly with FATX storage structures to provide file and directory management functionality.
